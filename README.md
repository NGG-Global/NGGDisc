# שאלון סגנונות התנהגות · מודל DISC

אפליקציית ווב סטטית למובייל, בעברית וב־RTL. 34 צמדי תכונות בשני צירים (מיקוד וקצב), גרף צירים עם מיקום מדויק ועמוד הסבר על ארבעת הסגנונות.

- אין שרת, אין analytics ואין שליחת נתונים. התשובות נשמרות רק ב־localStorage של הדפדפן.
- הפונטים (Rubik, Heebo) מתארחים בריפו (רישיון OFL), כך שאין פנייה לשירות חיצוני.
- HTML, CSS ו־JavaScript נקיים (ES modules), ללא framework וללא שלב build.

## תנועה ונגישות

שכבת תנועה עדינה מעל העיצוב המאושר (ללא שינוי בפריסה, בצבעים או בטקסטים):
- מעבר בין צמדים ובין סגנונות בכיוון הקריאה (קדימה נכנס משמאל, אחורה מימין). Progress מתמלא בהדרגה.
- בבחירה: סימון V מצטייר והאפשרות השנייה מתעמעמת לרגע, לפני המעבר האוטומטי (250ms).
- חשיפת התוצאה, רק בהגעה מהצמד האחרון: הרביע נצבע, הנקודה נעה מהמרכז למקומה, פסי הניקוד גדלים והמספרים נספרים.
- מצבי hover ולחיצה, ועומק עדין בכרטיסים.
- כשבמכשיר מוגדר `prefers-reduced-motion`, כל התנועה מבוטלת והמצב הסופי מוצג מיד. קוראי מסך מקבלים את הניקוד הסופי גם בזמן הספירה.

ערכי התזמון וה־easing מוגדרים כמשתנים ב־`assets/css/tokens.css`.

## הרצה מקומית

הקבצים נטענים ב־`fetch`, לכן צריך שרת מקומי (פתיחה ישירה של `index.html` מהדיסק לא תעבוד):

```bash
python3 -m http.server 8000
```

ואז לפתוח: <http://localhost:8000/>

## בדיקות

לוגיקת הניקוד נמצאת ב־`assets/js/scoring.js`, והבדיקות ב־`tests/scoring.test.js`. נדרש Node 18 ומעלה, ללא תלויות:

```bash
node --test
```


## עדכון תוכן

כל התוכן נמצא בשני קובצי JSON. אחרי עריכה מריצים `node --test`, בודקים מקומית ומבצעים push ל־`main`.

**`content/questions.json`**
- `prompt`: שורת השאלה. החלק שלפני הפסיק (`בעבודה,`) מוצג מעל הכותרת.
- `axes[].label`: שם הציר. המילה שאחרי ה־`·` מוצגת בכותרת השאלה ("חלק 1 מתוך 2 · מיקוד").
- `axes[].sides`: שמות הצדדים (מוצגים רק בתוצאה, לא בזמן המילוי).
- `axes[].pairs`: בכל ציר חייבים להיות בדיוק 17 צמדים. כל צמד כולל `id` ייחודי ואת שתי התכונות לפי מזהי הצדדים.
- תיקון ניסוח של תכונה לא משפיע על משתתפים באמצע מילוי. שינוי `id` של צמד מבטל את התשובה השמורה לאותו צמד.

**`content/styles.json`**
- `order`: סדר הסגנונות בצ'יפים ובלולאת הקודם/הבא.
- לכל סגנון: `name` (שם קצר), `title` (שם עם ה' הידיעה), `en`, `tagline`, `quote`, `communication`, `traits`, `howTo`.
- `quadrant` חייב להתאים לטבלת הניקוד (בדיקה אוטומטית מוודאת זאת).
- `notes`: שתי ההערות הראשונות מוצגות בכרטיס "איך לקרוא את התוצאה", והשלישית בתחתית מסך התוצאה.

## פרסום

`.github/workflows/pages.yml` מריץ את הבדיקות ומפרסם את שורש הריפו ל־GitHub Pages בכל push ל־`main`. בהגדרות הריפו, תחת Settings → Pages → Build and deployment, צריך לבחור Source = **GitHub Actions**.

מקור העיצוב והאפיון: חבילת המסירה `disc-quiz-handoff` (מוקאפים, `spec/flow.md`, `spec/scoring.md`, `spec/design-tokens.md`).
